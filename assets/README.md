# Team Dinner Bot App Assets

Optional Slack app icons can live in this directory.

Suggested filenames:

- `team-dinner-bot-icon.png` - source icon
- `team-dinner-bot-icon-512.png` - Slack upload size

Upload through `https://api.slack.com/apps/<APP_ID>/general` under
**App icon & Preview**.

Do not commit workspace-specific screenshots or images that reveal private Slack
app data.
